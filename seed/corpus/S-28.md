scribe ingests meeting notes, chats and tickets into the shared memory. researcher reads docs and vendor pages and writes findings with sources.

coder implements tickets and opens pull requests. reviewer checks pull requests against the tickets and the decisions they cite.

Every agent hands work off with the evidence it used.
