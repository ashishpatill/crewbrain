Options: Flutter or React Native with Expo. Meera and the coder agent compared both against the lesson player prototype.

Expo lets us share the TypeScript API client and validation code with the Next.js web app. Flutter would mean a second language and duplicated models.

Expo over-the-air updates let us fix the lesson player without waiting for store review.

Flutter's rendering was smoother in the prototype, but not enough to justify a second codebase. Decision: React Native with Expo. Meera decided, Asha approved.
