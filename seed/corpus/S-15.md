Options: Flutter or React Native with Expo. Lena and the coder agent compared both against the product lookbook and size-guide prototype for the shopping app.

Flutter shares the Dart size-guide and pricing packages with the internal tools app, so fitting logic and price calculations would not need to be rewritten. React Native would mean rebuilding those shared packages in a different language stack for the store app.

Flutter gives one codebase for both stores, covering phones from a single build for product browsing and checkout. There are no OTA updates, but staged rollouts let the team release to a small share of shoppers first and pause if problems appear.

The AR prototype held 60fps in Flutter and dropped frames in React Native when shoppers rotated a tent in 3D view. Decision: Flutter. Lena decided, Nia approved.
